hinoki.orm.foreign_key ¶

foreign_key(
    model: type[Model],
    *,
    on_delete: str,
    related_name: str = "",
    unique: bool = False,
    default: Any = dataclasses.MISSING,
) -> Any

Declare a column that references model's primary key.

author_id: UUID = foreign_key(User, on_delete="restrict", related_name="posts")

on_delete is required (restrict, cascade, set_null or no_action) so a deletion rule is always a decision. The relation is named after the column without _id and is loaded only by select_related / prefetch_related.

hinoki.orm.timestamps ¶

timestamps(
    updated_at: str = "updated_at",
    *,
    clock: Clock = utc_now,
) -> Callable[[M], M]

Update a declared datetime column on each ORM update statement.

Timestamp columns remain ordinary model fields, visible to type checkers and migrations. Declare their creation defaults with utc_now.

hinoki.orm.Related ¶

Class attribute that serves a loaded relation from the instance.

The framework installs it for every relation. To have the type checker know the attribute, declare it on the model without a value::

writer: ClassVar[Related[Writer]]
articles: ClassVar[Related[list[Article]]]
