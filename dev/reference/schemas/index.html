hinoki.schema.Schema ¶

Base class for schemas.

class PostCreate(Schema): title: str becomes a frozen, keyword-only dataclass. PostCreate.validate(data) checks decoded JSON strictly: no coercion, unknown keys refused by default, and every problem reported with its path.

validate_text classmethod ¶

validate_text(data: object) -> Self

Like validate for data that is all text, such as form fields ({"count": ["2"]}) or a parsed XML tree: text is first converted, in Rust, to the int, float and bool the fields declare. Anything that does not convert is left for validate to refuse. Before hooks see the raw text (each form value is a list of strings) and run first.

to_dict ¶

to_dict(*, exclude: Iterable[str] = ()) -> dict[str, Any]

The field values as Python objects (UUID, datetime stay what they are), nested schemas converted too. Fields left UNSET are omitted, so the result is exactly "what the client sent" for a partial update.

replace ¶

replace(**changes: Any) -> Self

A copy with changes (Python field names) applied. Every value is validated again, normalised and checked like a new instance, so the copy is as trustworthy as any other; fields that were never supplied stay unsupplied for dump(exclude_unset=True).

from_models classmethod ¶

from_models(
    rows: Iterable[object], **extra: Any
) -> list[Self]

Build a list from a synchronous iterable of model rows.

Each row follows from_model exactly. The iterable is consumed once, eagerly; this reads already-loaded attributes and never performs I/O.

from_model classmethod ¶

from_model(row: object, **extra: Any) -> Self

Build this schema from a model instance: every field is read from the attribute of the same name, extra supplies or overrides values (for computed fields). Nested models become nested schemas. A field the row lacks is an error, and an unloaded relation still raises RelationNotLoaded: nothing here does I/O.

hinoki.schema.field_check ¶

field_check(*names: str) -> Callable[[F], F]

Mark a method as a check on one or more fields: def ok(self, value).

It runs after the structural validation succeeded, so value already has the declared type, and may read the other fields through self. Raise Invalid(code, message) to refuse; it never changes the value. Checks are synchronous and must not do I/O: a rule that needs the database belongs in an operation, not in a schema.

hinoki.schema.field_normalize ¶

field_normalize(name: str) -> Callable[[F], F]

Mark a typed field canonicalizer: def trim(self, value: str) -> str.

Methods run synchronously after structural validation and return a replacement string; raise Invalid only from a check hook to reject.

hinoki.schema.object_check ¶

object_check(function: F) -> F

Mark a method as a check on the whole object: def ok(self). Runs after every field check passed or failed (all problems are reported together).

hinoki.schema.before_validate ¶

before_validate(function: F) -> F

Mark a classmethod or staticmethod that reshapes raw wire input: def prepare(cls, data: dict[str, Any]) -> dict[str, Any].

It runs on the decoded mapping, before any structural validation, for the schema and for every schema nested in it (lists, dicts, tuples, optionals and discriminated variants). Return the mapping to validate. The hook gets a shallow copy: replace nested values instead of mutating them, or the caller's input changes. Raise Invalid(code, message) to refuse; a KeyError, TypeError, ValueError, IndexError or AttributeError caused by unexpected input answers as invalid_input. The input is untrusted: check types before relying on them, stay synchronous and do no I/O. Plain unions of schemas that use it are refused: use a discriminator.

Declare a read-only value derived from the other fields of a Schema.

@computed_field def full_name(self) -> str reads like an attribute, is written by dump() and by JSON responses after the declared fields, and is documented as a readOnly property. It is never accepted as input and never stored. The return annotation gives its OpenAPI type; the method must be synchronous, take no arguments and not do I/O.

hinoki.fields.Secret ¶

Secret(value: str)

Text that never shows itself: repr, str, dump() and JSON responses give **********; reveal() returns the text.

The one secret type of Hinoki: a Schema field, a Settings field, a JWTKey and SessionSettings(csrf_secret=...) all take it.
