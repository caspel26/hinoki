Models and queries¶

Updated November 26, 2026 35 min read

Concrete models may omit @db.table(...) (or the compatible table= class keyword) to derive the table name <app>_<models> from the model's package and class name; label= and plural= override humanized display names. Explicit table names remain the safe choice for migration-backed histories and stable physical names.

field(
    *,

    unique: bool = False,

    | Any = dataclasses.MISSING,
) -> Any

Declare a column and, optionally, write-time constraints and validators.

id: UUID = field(primary_key=True, default_factory=uuid4)

name: str = field(constraints=Field(min_length=1), validators=(check_name,))

created_at: datetime = field(index=True, default_factory=utc_now) adds a single-column index, the same index as @db.indexed("created_at").

Constraints run before ORM writes. Custom validators are synchronous and raise ValueError to refuse a value; they must not perform I/O.

hinoki.orm.foreign_key ¶

foreign_key(
    model: type[Model],
    *,
    on_delete: OnDelete,
    related_name: str = "",
    unique: bool = False,
    validators: Sequence[Callable[..., None]] = (),
    default: Any = dataclasses.MISSING,
) -> Any

Declare a column that references model's primary key.

author_id: UUID = foreign_key(User, on_delete=OnDelete.RESTRICT)

on_delete is required and is an OnDelete member (RESTRICT, CASCADE, SET_NULL or NO_ACTION), so a deletion rule is always a decision; text such as "cascade" is refused. SET_NULL needs a column annotated | None. The relation is named after the column without _id and is loaded only by select_related / prefetch_related.

hinoki.pagination.CursorPagination dataclass ¶

CursorPagination(
    page_size: int | None = None,
    max_page_size: int | None = None,
    secret: str | None = None,
    ttl: int | None = None,
)

Strategy: ?cursor=TOKEN&limit=N, keyset pages with signed cursors.

The cursor is signed with secret (at least 32 bytes) and bound to the table, the ordering and the client filters of the query, so a changed or foreign token is a 422, never a 500. It is signed, not encrypted: it carries the sort-key values of the boundary row in readable form, so do not order by a column whose value must stay private. Clients should treat it as opaque. ttl (seconds) makes cursors expire. Anything left out comes from the application's pagination settings when the action is included; values given here win.
