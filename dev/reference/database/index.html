hinoki.db.DatabaseModule ¶

Bases: Module

Opens a Database for the worker and provides it to other modules.

app.install(DatabaseModule(url)); actions with transaction=True and other modules obtain it with ctx.get(Database). The pool is created in the worker's lifespan and closed when it ends.
