Core API: application, routing and HTTP¶

Updated November 24, 2026 33 min read

from hinoki import Hinoki, RouteGroup, Mount, http, errors and from hinoki.project import manifest_routes. Guides: function-based APIs, class-based APIs, register routes, errors.

hinoki.app.Hinoki ¶

Hinoki(
    *,
    settings: object | None = None,
    include: Sequence[Includable] | None = None,
    modules: Sequence[Module | type[Module]] = (),
    commands: Sequence[Command | type[Command]] = (),
    on_startup: Sequence[Hook] = (),
    on_shutdown: Sequence[Hook] = (),
    events: Sequence[Handlers] | None = None,
    email_templates: Sequence[TemplateBase] = (),
    startup_url: str | None = None,
    runtime: RuntimeConfig | None = None,
    title: str | None = None,
    version: str | None = None,
    openapi_url: str | Unset | None = UNSET,
    docs_url: str | Unset | None = UNSET,
    redoc_url: str | Unset | None = UNSET,
    llms_url: str | Unset | None = UNSET,
    openapi_version: Literal["3.1", "3.2"] | None = None,
    rules: RuleSet | None = None,
    enforce_rules: bool = True,
    waivers: str | Path | None = None,
    parsers: Sequence[Parser] | None = None,
    renderers: Sequence[Renderer] | None = None,
    middleware: Sequence[Middleware] | None = None,
)

A Hinoki application.

Registering routes builds the native router; nothing connects to anything, so factories returning Hinoki are safe to import and call. The instance is itself an ASGI callable (granian --interface asgi module:app); the first call freezes the declarations.

on_startup and on_shutdown list functions taking the worker's ModuleContext (async def or def). Startup hooks run once per worker after the modules have started; shutdown hooks run before they are closed, and only after a startup that completed.

events lists the Handlers collections whose typed event handlers run, in this order (see hinoki.events); an unlisted one does nothing.

email_templates lists the mail.Template objects the application sends. They go to the email module the email: EmailSettings field implies; with your own EmailModule pass them there instead. File templates are read and checked when each worker starts.

startup_url optionally reserves a public GET/HEAD endpoint that returns {"status": "ok"} after worker startup. It reports startup completion, not application, database, or event-loop health.

waivers names the owner's waiver file applied to the startup rules; it must exist. Without it, hinoki-rules.toml at the project root is used.

hinoki.routing.RouteGroup ¶

RouteGroup(
    prefix: str = "",
    *,
    access: Access | None = None,
    atomic: bool = False,
    errors: Sequence[type[APIError]] = (),
    cors: Cors | None = None,
    include_in_schema: bool = True,
    tags: Sequence[str] = (),
)

A function-based route group with a shared path prefix and defaults.

Decorated functions belong to this group and the group can be included once in a Hinoki application. Use API for class-based resources.

tasks = RouteGroup("/tasks", access=member_only, atomic=True,
                   errors=(NotFound,))

@tasks.get("/")                      # GET /tasks
async def listing(...): ...

@tasks.post("/", status=201)         # POST /tasks, atomic=True
async def create(...): ...

@tasks.get("/health", access=None)   # public on purpose, overriding the group

prefix is prepended to every path ("/" means the prefix itself), access is the default policy (pass access=None on an action to make it public), atomic=True makes POST/PUT/PATCH/DELETE transactional unless the action says atomic=False, errors are added to each action's own and cors is the default http.Cors (cors=None on an action keeps the application's policy). include_in_schema=False leaves every action out of the OpenAPI document unless it says include_in_schema=True, and tags come before the tags of each action. The result is an ordinary action: rules, OpenAPI and the MCP see no difference.

hinoki.project.manifest_rules ¶

The [project] rules list of hinoki.toml merged, in listed order, into one RuleSet for Hinoki(rules=manifest_rules()). The manifest is found as for manifest_routes; outside a project this raises ProjectError.

hinoki.http.Stream ¶

Stream(
    body: Source,
    *,
    status: int = 200,
    headers: ResponseHeaders = (),
    content_type: str | None = None,
    length: int | None = None,
)

Bases: Sourced

A body of bytes or str pieces (a str is sent as UTF-8).

body is an iterable or an async iterable; a plain iterable is advanced in the bounded sync executor. length declares the exact size when it is known, which gives the answer a content-length; without it the body is sent with chunked framing (HTTP/1.1) or until the stream ends (HTTP/2).

Server-sent events (text/event-stream) from an iterable of Event or str (a str is the data of one event). retry is the reconnection delay in milliseconds sent to the client first. keepalive is the seconds of silence after which a comment is sent: the default is execution.sse_keepalive, None turns it off. With root the file must be inside it once symbolic links are resolved; a missing file, a directory or a path that leaves root answers 404. filename adds a content-disposition: attachment header. The content-type is guessed from the name unless given. The whole file is sent with its size as content-length (ranges are not supported: accept-ranges: none).

hinoki.ratelimit.RateLimit ¶

RateLimit(
    limit: int,
    window: float,
    *,
    key: KeySource = "client",
    tenant: Tenant | None = None,
    cost: int = 1,
    scope: str | None = None,
    unknown_factor: int = 10,
    headers: bool = False,
    on_error: Literal["closed", "open"] = "closed",
    storage: Storage | None = None,
    clock: Callable[[], datetime] | None = None,
)

At most limit requests per window seconds for one key, counted in one shared table (or in memory, see storage).

A cell rate algorithm: a burst of limit is admitted at once and the sustained rate is limit per window. A refusal does not use up quota. The key is hashed in the native core, so a client address, user id or custom key never reaches SQL, logs or metrics.

key is "client" (the trusted address, an IPv6 one by its /64), "caller" (the authenticated caller, the client for an anonymous request) or a plain function of the context returning a string. scope defaults to the method and the route, so routes count apart; give routes the same scope to share a quota. tenant adds a segment to the key. A request with no known client shares one bucket unknown_factor times as large. on_error="closed" answers 503 when storage is unavailable, "open" admits the request and counts it.

headers=True adds RateLimit-Limit, RateLimit-Remaining and RateLimit-Reset (whole seconds) to admitted and refused answers. clock returns an aware datetime (hinoki.testing.ManualClock); the default is the system clock.
