Modules and runtime API¶

hinoki.modules.Module ¶

Base class for modules. Override lifespan to own resources.

name class-attribute ¶

name: str = ''

requires class-attribute ¶

requires: tuple[type[Module], ...] = ()

from_settings classmethod ¶

from_settings(settings: object) -> Module

Build the module from the application's settings. Override it to make Hinoki(modules=[YourModule]) work; the default says it is not supported.

lifespan(

hinoki.modules.ModuleContext ¶

Per-worker context handed to module lifespans.

provide/get is a typed, explicit registry — not a global service locator: one instance per worker, keyed by type.

settings = settings

hinoki.management.Command ¶

A project command with explicit arguments and module requirements.

Set name and optionally help/requires on a subclass. Override add_arguments to define CLI arguments and handle to execute the command. A synchronous or asynchronous handle is supported.

name class-attribute ¶

name: str = ''

help class-attribute ¶

help: str = ''
