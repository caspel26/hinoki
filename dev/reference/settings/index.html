Settings¶

hinoki.settings.Settings dataclass ¶

Base class: subclasses are keyword-only frozen dataclasses.

load classmethod ¶

load(
    *,
    prefix: str | None = None,
    env: Mapping[str, str] | None = None,
    dotenv: str | PathLike[str] | None = None,
    toml: str | PathLike[str] | None = None,
    overrides: Mapping[str, Any] | None = None,
    strict: bool = True,
) -> Self

Build the settings. Precedence: overrides, env (default: the process environment), dotenv, TOML file, and field defaults.

strict (default) makes a variable that starts with prefix but names no field an error, which catches typos; pass strict=False when another program shares the prefix. With an empty prefix nothing can be told apart from the rest of the environment, so no typo check happens.

prefix, dotenv and toml default to what the class declared.

explain classmethod ¶

explain(
    *,
    prefix: str | None = None,
    env: Mapping[str, str] | None = None,
    dotenv: str | PathLike[str] | None = None,
    toml: str | PathLike[str] | None = None,
    overrides: Mapping[str, Any] | None = None,
    strict: bool = True,
) -> list[SettingRow]

Load like load and say, for every value, where it came from: override, environment, .env, toml, file (a *_FILE variable) or default. Secrets are redacted.

example classmethod ¶

example(prefix: str | None = None) -> str

A .env.example: every variable with its default, required ones and secrets left blank, and a comment with the type.

describe ¶

describe() -> dict[str, Any]

The effective values as plain data, secrets redacted.

validate ¶

validate() -> None

Override to check relations between fields; raise ValueError. The message is shown in SettingsError: never put a field's value in it.
