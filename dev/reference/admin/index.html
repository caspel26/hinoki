hinoki.admin.ModelAdmin ¶

How one model appears in the admin. Subclass and override what you need.

  • queryset scopes every list, lookup, update and delete (it is part of the SQL statement); can gates view, add, change and delete for a model or a row. Row visibility belongs in queryset.
  • save and remove are the single places that write, so an application can run a domain command there instead of writing around its rules. assign columns are set by the server on creation and are not form fields; readonly columns are shown but never accepted; exclude columns are neither shown nor accepted.
  • After a default write the row must still be inside queryset; otherwise the write is rolled back.
