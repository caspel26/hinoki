Auth and crypto¶

hinoki.auth.Caller dataclass ¶

Who is making the request, as decided by authentication.

id is a stable string, user is your own object (the user row, a service account) and permissions is what the caller may do::

Caller(id="u1", user=user, permissions=frozenset({"posts:write"}))

hinoki.auth.Credentials dataclass ¶

The parts of a request a provider may inspect.

hinoki.auth.BaseAuth ¶

Bases: ABC

Base class of providers.

authenticate returns a principal, None when the request carries no credentials, and raises Unauthorized when credentials are present but invalid. Providers hold no per-request state.

hinoki.crypto.JWTKey dataclass ¶

One verification (and optionally signing) key.

HMAC secrets must be at least as long as the hash (32/48/64 bytes). For EdDSA the key is the 32-byte private seed, or with public=True the 32-byte public key of a verify-only deployment. kid is required when several keys are configured. The key is excluded from repr.

verify_only classmethod ¶

verify_only(kid: str | None, public_key: bytes) -> JWTKey

An Ed25519 public key (32 bytes) that can verify but never sign. Use this, not the plain constructor, wherever you hold only the public key: a public key passed as a seed would let anyone who knows it forge tokens.

hinoki.crypto.JWTAuth ¶

Bases: BearerAuth[T]

Bearer-token provider for JWTs. Subclass, set keys (and usually issuer and audience) and implement resolve_claims::

class Tokens(JWTAuth[User]):
    keys = [JWTKey("2026-11", "HS256", settings.jwt_secret)]
    issuer = "https://api.example.com"
    audience = "blog"

    async def resolve_claims(self, claims):
        subject, raw = claims.get("sub"), claims.get("scopes", [])
        if not isinstance(subject, str) or not isinstance(raw, list):
            return None  # claims are signed, but still untyped JSON
        try:
            user = await User.aget_or_none(id=UUID(subject))
        except ValueError:  # a signed token can still carry any text
            return None
        if user is None:
            return None
        scopes = frozenset(s for s in raw if isinstance(s, str))
        return Caller(subject, user, scopes)

hinoki.crypto.PasswordHasher ¶

Argon2id hashes in PHC format, computed off the event loop.

Parameters below the OWASP floor are refused unless allow_weak=True (tests only). workers bounds concurrent hashing, max_pending the queue; beyond that hash/verify raise HashingBusy (503). A task cancelled while its hash runs frees its slot but the thread finishes, so at most workers extra hashes can be in flight; hash_sync/verify_sync are not bounded. Only argon2id hashes are verified. For unknown users, verify against a fixed dummy hash so timing does not reveal who exists.
