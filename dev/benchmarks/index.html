Interpretation¶

Create throughput remains variable: at least one stack in each measured slice has a sample CV above 15%, including after ten samples in the create scenario. Treat these write measurements as inconclusive for close performance comparisons; the median and range are descriptive and do not establish a winner.

Method and limits¶

Each stack used the same PostgreSQL seed and request/response oracle. The verifier checked response content, status and SQL statement counts before measurement. Create uses per-statement autocommit in each implementation. The documented-stack and same-Granian ASGI slices answer different questions: Bolt stays on its own server and is not included in the ASGI same-server control.

This is one host and one run window. Drivers and ORM scheduling differ; equal pool settings do not imply identical behavior. The dataset is small and warm, networking is loopback, and this does not measure TLS, proxies, authentication, compression, memory, cold data or other workloads. A min-to-max range is descriptive, not a confidence interval. Raw JSON, environment metadata, server logs and verification output are retained in benchmarks/comparative/results/2026-11-15/; reproduction instructions are in benchmarks/comparative/README.md. Inspect them before drawing conclusions.
